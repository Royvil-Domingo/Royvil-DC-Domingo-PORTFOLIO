01 / About

A systems mindset, with the user in view.

I’m a student developer building a foundation across application development, databases, networking, and security. I’m most interested in software that replaces scattered manual steps with clearer, more reliable workflows.

My current work includes a Laravel-based management platform and a Flask borrowing application. These projects have given me practical experience connecting user interfaces to server-side logic, designing relational data flows, and thinking through access, validation, and operational needs.

I approach development as more than writing code: understand the problem, model the information, build the flow, and make the result easier to use and maintain.
